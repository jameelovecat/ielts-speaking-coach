# IELTS Speaking Coach

For IELTS speaking requests, read `skills/ielts-speaking-coach/SKILL.md` and follow it. Use the references linked from that file when relevant. The question-source guide points to community materials; do not copy third-party question banks, PDFs, or audio into this repository without a clear redistribution license.

Keep personal practice answers, recordings, scores, and private study notes out of this repository. Do not start a practice session just because someone is editing the repository.
