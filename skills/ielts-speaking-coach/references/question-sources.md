# 雅思口语题源

## 社区整理资料

- [zeeklog／IELTS 在线资料库](https://zeeklog.github.io/IELTS/)
- [zeeklog／IELTS GitHub 仓库](https://github.com/zeeklog/IELTS)

该社区资料按听力、阅读、写作和口语整理雅思备考材料，并提供剑桥真题资源。使用前请核对册数、Test、Part和原始页码；公开仓库中的题源链接不代表其中第三方材料可以被二次打包或转存。

## 使用规则

- 用户指定剑桥册数、Test或Part时，优先按指定范围查找，不随机换题。
- 题目确实来自可核对的资料时，标出「剑桥雅思 X，Test Y，Speaking Part Z」及可确认的页码。
- 如果网页或仓库内容无法读取，告诉用户并请其打开或提供该部分；不要假装已核对原题。
- 如果使用自行生成的练习题，明确标记为「雅思风格练习」，不要称为真题、回忆真题或押题。
- 公开 Skill 只引用题源，不打包第三方真题全文、PDF或音频。
